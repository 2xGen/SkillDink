# SkillDink

Visual pickleball courses. This Next.js app is the marketing site, course overview, sample lesson, and knowledge check for Pickleball Foundations.

Course copy lives in `lib/course.ts` until accounts, progress, and checkout are connected to Supabase.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push the repository to GitHub and import it in Vercel. The app uses the App Router and does not need extra build settings.
